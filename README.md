# Сантерра — готовые студии и коммерция в Балашихе

Многостраничный сайт проекта «Сантерра» (Sunterra): студии для жизни,
коммерческие помещения и инвестиционные сценарии в центре Железнодорожного
(Балашиха, ул. Новая, 22Б).

Стек: чистый HTML + CSS + JavaScript, без сборки. Дизайн — тёмные градиенты,
анимации, адаптивная вёрстка. Есть страницы разделов, журнал статей, RSS
и отдельная пустая лента для Дзена.

> **Публикация:** пошаговая инструкция — в файле
> [`КАК-ВЫЛОЖИТЬ.md`](КАК-ВЫЛОЖИТЬ.md): SSL, DNS, хостинг, Telegram-уведомления
> и проверка после запуска.

## Как открыть

**Вариант 1 — просто открыть файл.** Запустите `index.html` двойным кликом.
Сайт работает без сборки. Часть функций (формы, RSS, карта) лучше проверять
через локальный сервер.

**Вариант 2 — локальный сервер** (рекомендуется):

```bash
node server.js          # по умолчанию порт 4173
node server.js 4188     # другой порт
```

Сайт: <http://localhost:4173>.

## Формы заявок

Все формы (главная, разделы, статьи, модальное окно) отправляют JSON на `send.php`.

- **На хостинге с PHP** заявка уходит письмом на `info-sunterra@mail.ru`.
  Дополнительно можно включить Telegram-уведомления в `send.php`.
- **Локально** `server.js` перехватывает `POST /send.php` и печатает заявку
  в консоль — удобно проверять валидацию и состояние формы.
- Валидация: телефон 10–11 цифр, обязательное согласие, honeypot-поле `company`.
- Если форма не отправилась, показывается сообщение об ошибке и предлагается
  позвонить: `8 (800) 511-90-05`.

### Telegram-уведомления (опционально)

1. Создайте бота через `@BotFather` и получите токен.
2. Узнайте `chat_id` через `https://api.telegram.org/bot<токен>/getUpdates`.
3. Заполните `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в `send.php`.

Если константы пустые, заявки идут только на почту.

## RSS

- Основная лента: `https://apartamenty.poprostomy.ru/rss.xml`
- Лента для Дзена: `https://apartamenty.poprostomy.ru/dzen.xml` — намеренно пустая.

- После обновления новостей отредактируйте `rss.xml` и `lastBuildDate`.

## SEO

- У каждой страницы свои `title`, `description`, `canonical`, OG-теги.
- `sitemap.xml` содержит все 12 страниц.
- `robots.txt` закрывает `send.php`, `server.js` и служебные каталоги.
- Schema.org `ApartmentComplex` на главной.
- Изображения с `width`/`height`, `loading="lazy"` и `decoding="async"`.

## Проверка

```bash
node --check server.js
node --check script.js
node server.js 4188
```

Проверка формы:

```powershell
Invoke-RestMethod -Uri http://localhost:4188/send.php -Method Post `
  -ContentType "application/json" `
  -Body '{"name":"Тест","phone":"+7 (915) 120-05-50","format":"Студия","consent":"yes","company":""}'
```

Проверка RSS:

```powershell
(Invoke-WebRequest -Uri http://localhost:4188/rss.xml).Headers["Content-Type"]
```

Проверено: 320–1440 px, отсутствие горизонтального скролла, отсутствие ошибок JS,
фильтры, лайтбокс, модальное окно, таймер, ленивые карта и видео, прогресс чтения,
доступность (axe: 0 нарушений WCAG 2.1 A/AA).
