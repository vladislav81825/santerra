# САНТЕРРА — лендинг жилого комплекса

Тёмная премиальная тема для проекта «Сантерра» (Sunterra) — готовые студии
и коммерческие помещения в Балашихе, мкр. Железнодорожный, ул. Новая, д. 22Б.

Дизайн: тёплый «солнечный» акцент, редакционная типографика (Unbounded + Inter),
крупные секции, карточки форматов, галерея, лента обновлений RSS и формы заявок.

> **Публикация на домен:** пошаговая инструкция — в файле
> [`КАК-ВЫЛОЖИТЬ.md`](КАК-ВЫЛОЖИТЬ.md). Там же — SSL, DNS, настройка
> Telegram-уведомлений и что проверить после запуска.

## Как открыть

**Вариант 1 — просто откройте файл.** Двойной клик по `index.html`.
Все ресурсы локальные, интернет нужен только для шрифтов Google Fonts,
видео (Rutube / mp4) и карты Яндекса. Отправка форм по `file://` не работает —
для неё нужен PHP или локальный сервер.

**Вариант 2 — локальный сервер** (корректная работа ссылок, RSS и заглушки форм):

```bash
node server.js          # по умолчанию порт 4173
node server.js 4188     # другой порт
```

Затем откройте <http://localhost:4173>.

## Формы заявок

Обе формы (внизу страницы и в модальном окне) отправляют JSON на `send.php`.

- **На хостинге с PHP** заявка уходит письмом на `info-sunterra@mail.ru`.
  Адрес получателя, отправитель и Telegram настраиваются в начале `send.php`.
- **Локально** `server.js` перехватывает `POST /send.php` и печатает заявку
  в консоль — удобно проверять валидацию и маску телефона.
- Валидация: телефон 10–11 цифр, обязательное согласие, honeypot-поле `company`.
- Если отправить не удалось, форма не показывает ложный успех, а предлагает
  позвонить: `8 (800) 511-90-05`.

### Telegram-уведомления (необязательно)

1. Создайте бота через `@BotFather` и получите токен.
2. Узнайте `chat_id` через `https://api.telegram.org/botТОКЕН/getUpdates`.
3. Впишите значения в `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в `send.php`.

Если константы пустые, заявки идут только на почту.

## RSS-лента

- Адрес: `https://apartamenty.poprostomy.ru/rss.xml`
- В `<head>` подключена ссылка `rel="alternate"`.
- На странице есть блок «Обновления» с открытием ленты и копированием ссылки.
- Лента статическая: при изменении цен/наличия отредактируйте `rss.xml`
  и обновите дату `lastBuildDate`.

## Локальная проверка

```bash
node --check server.js
node --check script.js
node server.js 4188
```

Проверка формы:

```powershell
Invoke-RestMethod -Uri http://localhost:4188/send.php -Method Post `
  -ContentType "application/json" `
  -Body '{"name":"Тест","phone":"+7 (915) 120-05-50","format":"Студия","consent":"yes","company":""}'
```

Проверка RSS:

```powershell
(Invoke-WebRequest -Uri http://localhost:4188/rss.xml).Headers["Content-Type"]
```
